# TraveMirea — Туристическое агентство (Контрольная работа №3)

Классический адаптивный веб-сайт туристического агентства **TraveMirea**, разработанный на чистых **HTML5, CSS3 и JavaScript (Vanilla JS)** без использования фреймворка Bootstrap. Проект выполнен по подходу **Mobile First** с соблюдением требований доступности (WCAG / Lighthouse Accessibility) и адаптивной вёрстки.

---

## 1. Структура проекта

```text
trave-mirea/
├── index.html                  # Главная страница (баннер, преимущества, популярные туры, отзывы, карта)
├── catalog.html                # Каталог туров с фильтрацией по формату отдыха и интерактивной схемой маршрутов
├── product.html                # Подробная страница гранд-тура «Сердце Байкала и Ольхон», таблица заездов и фотогалерея

├── contacts.html               # Страница офисов продаж, прямых контактов и сервисных пакетов
├── css/
│   ├── style.css               # Базовые стили (Mobile First), цветовая палитра, компоненты, тёмная тема, доступность
│   └── responsive.css          # Медиазапросы для разрешений 360px, 430px, 768px, 1024px, 1440px
├── js/
│   └── main.js                 # Чистый JS: доступное меню и модальные окна, фильтры, карусель, галерея, калькулятор

├── lighthouse/                 # Отчёты и скриншоты проверки доступности (Accessibility — 100/100)
├── README.md                   # Документация проекта
└── .gitignore                  # Исключения для Git
```

## 2. Реализованные адаптивные решения (Mobile First)

Базовые правила в `css/style.css` ориентированы на мобильные экраны от **360px**, а расширение макета выполняется через `@media (min-width: ...)` в файле `css/responsive.css`:

- **360px (мобильный телефон):** одноколоночная сетка CSS Grid и Flexbox, компактная шапка, мобильное бургер-меню, адаптивное представление таблиц в виде карточек (`data-label`), полное отсутствие горизонтальной прокрутки (`scrollWidth === innerWidth`).
- **430px (большой мобильный телефон):** кнопки первого экрана располагаются в ряд, двухколоночная сетка внутри карточек расписания заездов и чекбоксов дополнительных опций калькулятора.
- **768px (планшет):** двухколоночная сетка карточек туров (`repeat(2, minmax(0, 1fr))`), три колонки преимуществ, переход таблицы расписания заездов из карточного режима в классический табличный вид (`display: table`), двухколоночная форма бронирования.
- **1024px (небольшой компьютер / ноутбук):** горизонтальная навигационная панель, двухколоночный главный баннер (`7fr 5fr`), сетка каталога в 3 колонки, карта маршрутов с боковой легендой, 4-колоночный `Footer` (`4fr 2fr 3fr 3fr`) со строго вертикальными списками в разделах «Навигация» и «Связаться».
- **1440px (широкий экран):** центрированный контейнер `max-width: 1340px`, увеличенные внутренние отступы секций и карточек.

## 3. Адаптивные изображения (Responsive Images)

Для всех фотографий путешествий подготовлены 3 версии разрешения (`480w`, `800w`, `1200w` в папке `images/`):
- Используются теги `<picture>` с `<source media="...">` на ключевых баннерах (`index.html`, `product.html`, `contacts.html`).
- Используются атрибуты `srcset` и `sizes` у всех карточек туров и элементов фотогалереи, чтобы мобильные устройства загружали облегчённые изображения `480w`, а настольные экраны — `800w` и `1200w`.
- Все изображения ограничены правилом `max-width: 100%; height: auto; object-fit: cover;` и не выходят за пределы родительских контейнеров.

## 4. Доступность (Accessibility)

В проекте выполнены все требования доступности:
1. **Skip Link (`<a class="skip-link" href="#main-content">`):** ссылка пропуска навигации к основному содержимому на каждой странице (появляется при фокусе с клавиатуры `Tab`).
2. **Семантическая разметка:** использованы `<header>`, `<nav>`, `<main id="main-content">`, `<section>`, `<article>`, `<figure>`, `<figcaption>`, `<address>`, `<footer>`.
3. **Иерархия заголовков:** ровно один главный заголовок `<h1>` на каждой странице и строгая последовательность `h1 → h2 → h3` без пропусков уровней.
4. **Доступные формы:** каждое поле ввода (`input`, `select`, `textarea`) связано со своим `<label for="...">`, итоговая сумма калькулятора выводится в семантический тег `<output>` с `aria-live="polite"`.
5. **Видимый фокус:** отчётливая контрастная рамка `:focus-visible` (`outline: 3px solid var(--wave-orange); outline-offset: 3px;`) для всех ссылок, кнопок и полей форм.
6. **Управление с клавиатуры:**
   - Мобильное меню и модальные окна закрываются по клавише `Escape`, поддерживают ловушку фокуса (`Tab` / `Shift+Tab`) и возвращают фокус на кнопку-триггер после закрытия.
   - Карусель отзывов и фотогалерея поддерживают переключение стрелками клавиатуры `ArrowLeft` и `ArrowRight`.
7. **Цветовой контраст:** светлая палитра с глубокими синими и голубыми оттенками (`#013c58`, `#00537a`, `#f4fcff`, `#a8e8f9`) и поддержкой переключения в тёмную тему обеспечивает контрастность текста выше стандарта WCAG AA (более 7:1).

## 5. Дополнительные интерактивные фичи (авторские улучшения)

1. **Плавное переключение светлой и тёмной темы (`localStorage`)** — анимированная смена цветовой палитры всех блоков страницы и плавный поворот иконки солнца/луны в шапке.
2. **Живой поиск и сортировка туров в каталоге (`catalog.html`)** — мгновенная фильтрация карточек по ключевым словам и сортировка по возрастанию/убыванию цены и длительности поездки.
3. **Избранные туры с сохранением в браузере (`localStorage`)** — кнопка-сердечко на каждой карточке тура на главной и в каталоге, счётчик избранного и отдельная вкладка фильтра «Избранное».
4. **Система промокодов в калькуляторе (`order.html`)** — поддержка промокодов `MIREA10` (-10%), `LETO2026` (-7%) и `BAIKAL5` (-5 000 ₽) с мгновенным пересчётом итоговой суммы.
5. **Интерактивный чек-лист путешественника (`product.html`)** — список необходимых вещей в тур с прогресс-баром в процентах и автосохранением в `localStorage`.

## 7. Локальный запуск проекта

Проект не требует сборки и внешних зависимостей. Для запуска локального веб-сервера выполните в терминале из папки `trave-mirea/`:

```bash
python3 -m http.server 8765
```

После запуска откройте в браузере адрес: `http://localhost:8765` (или откройте `index.html` напрямую в любом современном браузере).
